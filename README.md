# Phani Bhushan Hospitals — React Website

Responsive healthcare website concept using a premium gold-and-white palette, Khula and Roboto typography, and mobile-first navigation.

## Features
- Responsive desktop, tablet and mobile layouts
- Gold and white healthcare branding
- Hero section with Book Appointment and Watch Overview actions
- About, specialties, emergency care, patient journey and contact sections
- Appointment and callback form UI
- Sticky mobile Call Hospital, Book Appointment and WhatsApp actions
- Uses Lucide icons and Google Fonts

## Run locally

```bash
npm install
npm run dev
```

For a production build:

```bash
npm run build
npm run preview
```

## Before publishing
- Replace placeholder hospital phone number, address and WhatsApp number in `src/main.jsx`.
- Connect appointment and callback forms to the hospital's booking system or backend. They are front-end demo forms only.
- Replace the overview panel with the approved hospital overview video if available.
- Verify medical services, doctor details, emergency contact information and all claims with the hospital.
- Hospital imagery currently loads from Unsplash and fonts from Google Fonts, so an internet connection is required for those assets.
